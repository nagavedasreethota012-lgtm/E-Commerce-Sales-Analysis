# E-Commerce Business Analysis – Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze e-commerce business performance. The dashboard provides insights into sales, products, customers, orders, and overall business trends.

## 🎯 Objectives

- Analyze overall e-commerce sales performance
- Identify top-performing products and categories
- Understand customer purchasing behavior
- Analyze order trends and business performance
- Identify key patterns and trends using interactive visualizations
- Support data-driven business decisions

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Transformation

## 📊 Key Analysis

- Sales performance
- Product and category analysis
- Customer analysis
- Order analysis
- Revenue and business trends
- Key performance indicators (KPIs)

## 📈 Dashboard

The Power BI dashboard provides interactive charts, graphs, KPIs, filters, and slicers for exploring the e-commerce business data.

## 📁 Project Files

- `E-Commerce_Analysis.pbix` – Power BI dashboard and analysis
- `dashboard.png` – Dashboard preview
- Dataset is not included in this repository.

## 💡 Key Insights

The analysis helps identify important sales trends, high-performing products and categories, customer behavior, and overall e-commerce business performance.

## 📝 Conclusion

This project demonstrates the use of Power BI for transforming data into meaningful visual insights and supporting data-driven business decisions.
